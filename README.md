# Land Allocation Modeling with New Theory Principles
This is a mathematical and computational model for land allocation using new theory principles written in C++

* Submitted to the Mathematical Modeling Challenges 2026
* Honored for good-level problem solving performance

<img width="512" alt="image" src="https://github.com/user-attachments/assets/77628c9f-acee-4f97-9594-8bac74146448" />

The task is, given a 1-rai (1600 m^2) land in the shape of an arbitrary rectangle, we have to
1. Measure or calculate the area and dimensions using geometry.
2. Analyze the terrain and orientation of the land: water availability, sunlight direction, and road accessibility
3. Develop a flexible model to decide the most appropriate ratio for water, rice, crops, and utility area.
4. Explain how the model reflects the core philosophy of the "New Theory" in terms of both "Sustainability" and "Suitability".

We, the researchers, hereby publish the source code of computational part, the final report and summary.\
